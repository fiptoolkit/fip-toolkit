Onglet Journal

Le journal d'activité enregistre en temps réel tout ce que fait CopyMove : démarrages, exécutions de règles, résultats, avertissements et erreurs. C'est l'outil de référence pour comprendre ce qui s'est passé et diagnostiquer un problème.

Actions disponibles

  1. Rafraîchir (bouton à icône, infobulle au survol) — recharge le journal pour afficher les dernières entrées
  2. Effacer — supprime toutes les entrées du journal, après confirmation. Cette action est irréversible
  3. Exporter — enregistre le journal dans un fichier texte (copymove-logs-AAAA-MM-JJ.txt). Utile pour conserver une trace ou la transmettre au support
  4. Copier — copie le contenu du journal dans le presse-papier
  5. Rafraîchissement automatique — activé par défaut (toutes les 2 secondes). Décochez cette case si vous souhaitez figer l'affichage pendant une consultation
L'export et la copie portent sur l'intégralité du journal, sans tenir compte du niveau ni de la recherche affichés à l'écran.

Filtrer le journal

Trois éléments permettent de cibler rapidement les entrées qui vous intéressent :

  1. Niveau — affichez toutes les entrées, ou restreignez à un niveau précis (votre choix est mémorisé) :
    • Info — opérations normales (démarrage, exécution réussie…)
    • Warn — situations anormales non bloquantes (avertissements)
    • Error — erreurs qui ont empêché une opération de se terminer
  2. Recherche — saisissez un mot-clé pour n'afficher que les entrées dont le message le contient. Pratique pour retrouver les entrées liées à une règle précise
  3. Le compteur indique le nombre d'entrées affichées par rapport au total enregistré

Lire le journal

Chaque ligne du tableau représente un événement avec trois informations. Les entrées les plus récentes sont affichées en premier, et le journal conserve les 500 dernières :

  1. Horodatage — date et heure exactes de l'événement.
  2. Niveau — gravité de l'événement, indiquée par une couleur : bleu pour Info, orange pour Warn, rouge pour Error.
  3. Message — description de l'événement.

Quelles entrées sont enregistrées ?

Le niveau de capture du journal se configure dans l'onglet Paramètres, section Niveau du journal. Par défaut, seuls les avertissements et les erreurs sont enregistrés.

Si vous cherchez à comprendre pourquoi une règle ne se comporte pas comme prévu, passez temporairement en mode Tout dans les Paramètres : toutes les opérations seront alors consignées en détail.

N'oubliez pas de revenir au mode Avertissements et erreurs une fois le diagnostic terminé — le mode Tout génère beaucoup d'entrées et peut légèrement ralentir l'extension.
