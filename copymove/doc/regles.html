Onglet Règles

C'est l'onglet central de CopyMove. Il regroupe toutes vos règles de copie et de déplacement, et permet de les créer, les modifier et les réorganiser.

Le tableau des règles

  1. La poignée ⋮ à gauche de chaque ligne permet de réorganiser l'ordre d'exécution par glisser-déposer — l'ordre des lignes détermine l'ordre d'exécution.
  2. Les colonnes d'information résument chaque règle en un coup d'œil :
    • Nom — nom descriptif de la règle. Une icône d'avertissement peut le précéder : conflit de sources (la règle partage un dossier source avec une autre règle active — l'infobulle nomme cette règle) ou compte ou dossier à corriger (règle importée dont la configuration est invalide : éditez-la ; son lancement est désactivé tant qu'elle n'est pas corrigée).
    • Action — Copier ou Déplacer.
    • Source(s) — premier dossier source configuré, suivi de « +N » s'il y en a d'autres. Survolez la cellule pour afficher le chemin complet en infobulle.
    • Destination — dossier de destination. Survolez la cellule pour afficher le détail complet en infobulle si le texte est tronqué.
    • Temporalité — résumé du déclenchement configuré (ex : « 2 horaires »). Survolez la cellule pour afficher le détail complet (déclenchement et profil d'exécution) en infobulle.
  3. Le Statut (✓ Actif / ✗ Inactif) est directement cliquable : un clic active ou désactive la règle sans ouvrir le panneau d'édition. L'activation d'une règle qui partage des sources avec une règle déjà active demande confirmation. Une règle désactivée n'est pas exécutée automatiquement, mais reste lançable manuellement.
  4. La colonne Actions regroupe : ▶ Lancer la règle manuellement, ✏️ Éditer ses réglages (rouvre le panneau de création pré-rempli avec les paramètres actuels), 🗑️ Supprimer la règle (une confirmation est demandée avant suppression définitive)

Au-dessus du tableau, le bouton + ajoute une règle et le bouton Actualiser (↻) recharge la liste.

Créer une règle — Identification et action

Cliquez sur le bouton + (Ajouter une règle) pour ouvrir le panneau de création sur la droite de l'écran.

  1. ID de la règle — identifiant unique de la règle : 1 à 100 caractères, lettres, chiffres, tiret et tiret bas uniquement.
  2. Nom de la règle — donnez un nom descriptif qui vous permettra de l'identifier facilement dans le tableau (ex : Archiver les factures).
  3. Règle activée — décochez cette case si vous souhaitez créer la règle sans l'activer immédiatement.
  4. Sous Type d'action, choisissez comment les courriels seront traités :
  5. Déplacer — les courriels sont déplacés vers le dossier destination et retirés du dossier source.
  6. Copier — les courriels sont copiés vers le dossier destination et conservés dans le dossier source. L'option de suppression des dossiers sources n'est alors pas disponible.

Créer une règle — Dossiers sources

  1. Sélectionnez le compte de messagerie dans la liste déroulante
  2. Choisissez le dossier à traiter dans l'arborescence
  3. Ajoutez jusqu'à 5 dossiers sources pour une même règle via le bouton + (Ajouter une source) — tous les dossiers sources doivent appartenir au même compte, et un même dossier ne peut pas figurer deux fois
  4. Si vous avez choisi Déplacer, la case Supprimer les dossiers sources s'ils sont vides après déplacement est cochée par défaut ; décochez-la pour les conserver. Un dossier supprimé par CopyMove n'est pas signalé comme absent pendant quelques jours (voir Dossiers source absents)

Créer une règle — Dossier destination

  1. Sélectionnez le compte de messagerie destination — il peut être différent du compte source
  2. Cliquez sur le bouton Parcourir pour ouvrir l'arborescence
  3. Choisissez le dossier destination dans l'arborescence
Le dossier destination ne peut pas être l'un des dossiers sources. Si la suppression des dossiers sources vides est activée, il ne peut pas non plus être l'un de leurs sous-dossiers.

Créer une règle — Déclenchement

La section Déclenchement définit quand la règle s'exécute automatiquement. Trois modes sont disponibles :

  • Heures fixes — la règle s'exécute exactement aux heures que vous indiquez (10 au maximum, sans doublon, ajoutées avec le bouton +). Exemple : 4 08:00 et 5 15:00.
  • Intervalle régulier — la règle s'exécute toutes les X heures et/ou minutes (minimum 10 minutes). Exemple : toutes les 2 heures, ou toutes les 30 minutes.
  • Au démarrage de l'extension — la règle s'exécute une fois après un délai optionnel (de 0 à 60 minutes), décompté depuis le démarrage de Thunderbird. Si l'extension se charge plus tard que Thunderbird lui-même, le délai démarre au chargement réel de l'extension, pas au lancement de Thunderbird.

Une fois votre choix fait, cliquez sur 6 Enregistrer en bas du panneau.

Créer une règle — Profil d'exécution

La section Profil d'exécution permet d'assigner un profil spécifique à cette règle. Un profil définit la vitesse à laquelle CopyMove communique avec votre serveur de messagerie.

Par défaut, la règle utilise les Paramètres globaux définis dans l'onglet Paramètres (ou le profil pré-conçu défini comme défaut global). Si votre serveur réagit différemment selon les opérations, vous pouvez assigner un profil dédié à cette règle uniquement.

Le menu déroulant liste tous les profils disponibles : le profil par défaut (Paramètres globaux), les profils pré-conçus (Rapide, Prudent, Sécurisé, Très sécurisé), et vos éventuels profils personnalisés.

Les profils se créent et se configurent dans l'onglet Paramètres. Consultez cette section pour en savoir plus sur les profils pré-conçus et les profils personnalisés.

Lancer une règle manuellement — ajustement avant exécution

Cliquer sur ▶ Lancer dans le tableau ouvre systématiquement un panneau latéral « Exécution : nom de la règle » d'ajustement avant de démarrer le traitement.

  1. Si la règle est désactivée, une confirmation est demandée avant de continuer — un avertissement supplémentaire apparaît si la règle partage des dossiers sources avec une règle active, pour éviter tout conflit de traitement.
  2. Le panneau affiche les réglages du profil d'exécution actuel de la règle, organisés en accordéons dépliables — vous pouvez les modifier librement avant de lancer.
  3. Mettre à jour le profil — présent uniquement si la règle utilise un profil personnalisé — enregistre définitivement vos modifications dans ce profil, sans lancer l'exécution. Une confirmation d'écrasement est demandée.
  4. Exécuter lance immédiatement le traitement avec les valeurs actuellement affichées — si vous n'avez pas cliqué sur "Mettre à jour le profil" au préalable, ces valeurs ne servent que pour ce lancement et ne sont pas conservées.
Une fois l'exécution lancée, la barre de progression correspondante est décrite dans la section Pendant l'exécution ci-dessous.

Pendant l'exécution

Lorsqu'une règle est en cours d'exécution, une barre de progression apparaît en haut de l'onglet. Elle indique :

  1. Le nom de la règle en cours de traitement, précédé de sa position (« Règle 2/5 — ») lorsque plusieurs règles s'enchaînent, avec le profil d'exécution utilisé
  2. L'étape en cours (décompte des courriels, copie/déplacement, vérification)
  3. Le nombre de courriels traités (« Déplacement : x / y courriels ») et le pourcentage d'avancement
  4. Le temps écoulé depuis le début de l'exécution (mm:ss)

Le bouton 5 STOP permet d'interrompre l'exécution à tout moment. Les courriels déjà traités ne sont pas annulés.

Pour lancer une règle sans ouvrir les paramètres, utilisez la section Exécution manuelle directement depuis la fenêtre de CopyMove.
