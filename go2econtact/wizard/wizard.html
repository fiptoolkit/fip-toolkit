Votre domaine interne

Le domaine interne correspond à votre organisation (entreprise, association, etc.). Les emails de ce domaine ne recevront pas d'accusé de réception par défaut, sauf si vous les ajoutez explicitement aux inclusions.

💡 Utilisez *.domaine.fr pour inclure tous les sous-domaines (ex: paris.societe.fr, lyon.societe.fr)

Exemples

  • entreprise.fr → Bloque uniquement @entreprise.fr
  • *.entreprise.fr → Bloque @paris.entreprise.fr, @lyon.entreprise.fr, etc.
ℹ️ Pourquoi bloquer les emails internes ?

Par défaut, on évite d'envoyer des accusés de réception aux collègues de votre organisation pour ne pas encombrer inutilement les boîtes email internes. Les AR sont réservés aux contacts externes (clients, partenaires, etc.).

Qui ne recevra JAMAIS d'accusé de réception ?

Définissez les adresses, domaines ou patterns qui ne doivent jamais recevoir d'accusé de réception automatique.

Domaines à exclure

Bloquez tous les emails d'un domaine complet (ex: tous les emails de publicite.fr)

💡 Vous pouvez utiliser *. pour exclure tous les sous-domaines

Adresses spécifiques à exclure

Bloquez des adresses email précises (ex: robot@exemple.com)

Patterns automatiques à exclure

Bloquez des types d'emails automatiques (ex: tous les noreply@*)

💡 Utilisez * comme joker (ex: noreply@* bloque tous les noreply)

Patterns recommandés

  • noreply@* - Emails "ne pas répondre"
  • no-reply@* - Variante avec tiret
  • postmaster@* - Administrateurs serveurs mail
  • mailer-daemon@* - Emails d'erreur automatiques

Sujets à exclure

Bloquez les emails selon leur objet, indépendamment de l'expéditeur (ex: réponses automatiques, newsletters).

💡 [COMMENCE]texte · [CONTIENT]texte · [FINIT]texte — insensible à la casse
ℹ️ Différence domaine / adresse / pattern ?
  • Domaine : Bloque TOUS les emails d'un domaine (ex: spam.com bloque contact@spam.com, info@spam.com, etc.)
  • Adresse : Bloque UNE adresse précise (ex: robot@service.fr)
  • Pattern : Bloque selon un motif (ex: noreply@* bloque tous les noreply de tous les domaines)

Qui recevra TOUJOURS un accusé de réception ?

Ces adresses/domaines ont la priorité ABSOLUE : elles recevront un AR même si elles sont dans les exclusions ou le domaine interne.

⚠️ Important : Les inclusions annulent TOUTES les autres règles. Utilisez-les pour créer des exceptions ciblées.

Adresses qui recevront TOUJOURS un AR

Ajoutez des adresses qui doivent recevoir un AR même si elles sont bloquées ailleurs

Domaines qui recevront TOUJOURS un AR

Forcez l'envoi d'AR pour tous les emails d'un domaine

Cas d'usage typiques

  • Patron dans domaine interne : patron@entreprise.fr reçoit un AR même si entreprise.fr est bloqué
  • Client VIP : vip@client.com reçoit toujours un AR
  • Test interne : test@entreprise.fr pour vérifier que l'extension fonctionne

Comment importer dans Go2Econtact ?

  1. Téléchargez le fichier JSON ci-dessus
  2. Ouvrez Thunderbird - Go2Econtact
  3. Allez dans l'onglet Général - Filtrage - Exclusions
  4. Cliquez sur "Importer configuration"
  5. Sélectionnez le fichier téléchargé
