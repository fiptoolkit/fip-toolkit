1. Présentation générale

Objectif de Go2Econtact

Go2Econtact est une extension pour Thunderbird conçue pour automatiser l'envoi d'accusés de réception (AR) différés en cas d'absence. Elle s'intègre parfaitement avec l'extension Send Later pour programmer l'envoi de vos AR selon vos règles personnalisées.

📧 Cas d'usage : Vous partez en vacances ? Go2Econtact peut envoyer automatiquement un AR différé à tous vos contacts professionnels, tout en excluant les newsletters et les emails internes.

Fonctionnalités principales

  • 🎨 Gestion de templates personnalisables : Créez des messages d'absence personnalisés avec des variables dynamiques (nom, prénom, date de retour, etc.)
  • 🔍 Filtrage intelligent : Définissez des règles d'inclusion/exclusion pour contrôler qui reçoit vos AR (domaines, expéditeurs, mots-clés)
  • 👥 Multi-comptes : Gérez plusieurs comptes email avec des templates et règles distincts pour chaque compte
  • 📊 Analyse détaillée : Suivez en temps réel les décisions de filtrage et optimisez vos règles
  • 🐛 Logs de débogage : Consultez l'historique complet des opérations pour diagnostiquer tout problème
  • 🔒 Sécurité UUID : Validation stricte de l'extension Send Later pour éviter les conflits

Architecture et intégration

Go2Econtact fonctionne en étroite collaboration avec l'extension Send Later. Voici comment :

  1. Réception d'un email : Thunderbird reçoit un nouvel email
  2. Analyse par Go2Econtact : L'extension analyse l'email selon vos règles de filtrage
  3. Génération de l'AR : Si l'email passe les filtres, Go2Econtact génère un AR basé sur votre template
  4. Programmation via Send Later : L'AR est transmis à Send Later pour envoi différé selon le délai configuré
  5. Envoi automatique : Send Later envoie l'AR au moment programmé

⚠️ Prérequis : L'extension Send Later doit être installée et configurée dans Thunderbird pour que Go2Econtact fonctionne. Go2Econtact ne peut pas envoyer d'AR sans Send Later.

Interface utilisateur

L'interface de Go2Econtact est organisée en 6 onglets principaux :

  • 🏠 Général : Configuration globale (délai d'envoi, détection doublons, logging)
  • 👥 Comptes : Association des templates aux comptes email
  • 🎨 Templates : Création et édition des messages d'absence
  • 🔍 Règles : Définition des règles d'inclusion/exclusion
  • 📊 Analyse : Suivi des décisions de filtrage et optimisation
  • 🐛 Logs : Consultation des logs de débogage

Workflow typique

Voici un exemple de workflow complet pour configurer Go2Econtact :

  1. Installation : Installer Go2Econtact et Send Later depuis les addons Thunderbird
  2. Configuration globale : Définir le délai d'envoi (ex: 15 min) dans l'onglet Général
  3. Création d'un template : Créer un message d'absence dans l'onglet Templates
  4. Association du template : Associer le template à un compte dans l'onglet Comptes
  5. Définition des règles : Exclure les newsletters et emails internes dans l'onglet Règles
  6. Activation : Activer l'extension pour le compte concerné
  7. Suivi : Consulter l'onglet Analyse pour vérifier le bon fonctionnement

✅ Bon à savoir : Une fois configuré, Go2Econtact fonctionne de manière totalement autonome. Vous n'avez plus qu'à activer/désactiver l'extension selon vos périodes d'absence.

2. Onglet Général

Vue d'ensemble

L'onglet Général regroupe les paramètres globaux de Go2Econtact qui s'appliquent à tous les comptes email configurés. C'est le point de départ pour configurer l'extension.

Délai d'envoi des AR

Ce paramètre définit le temps d'attente avant l'envoi de l'AR automatique.

⏱️ Valeur par défaut : 15 minutes

📏 Plage autorisée : 1 à 1440 minutes (24 heures)

💡 Recommandation : Un délai de 15 à 30 minutes est idéal pour laisser le temps de répondre manuellement aux emails urgents.

Pourquoi un délai ?

  • Permet de répondre manuellement aux emails urgents avant l'envoi automatique de l'AR
  • Évite d'envoyer un AR si vous êtes finalement disponible pour répondre
  • Réduit le risque d'envoyer des AR en double (si vous désactivez l'extension rapidement)

Période de détection des doublons

Ce paramètre définit la durée pendant laquelle Go2Econtact se souvient d'avoir déjà envoyé un AR à un expéditeur donné.

⏱️ Valeur par défaut : 24 heures

📏 Plage autorisée : 1 à 168 heures (7 jours)

💡 Recommandation : 24 heures pour une absence courte, 48-72 heures pour une absence longue.

Fonctionnement :

Si un expéditeur vous envoie plusieurs emails dans la période définie, Go2Econtact n'enverra qu'un seul AR. Cela évite de spammer vos correspondants avec plusieurs AR pour chaque email reçu.

⚠️ Attention : Si vous réduisez cette période, vous risquez d'envoyer plusieurs AR au même expéditeur. À l'inverse, une période trop longue pourrait empêcher l'envoi d'AR légitimes lors d'absences répétées.

Mode de logging détaillé

Active ou désactive l'enregistrement détaillé des événements dans les logs de débogage.

🔍 Mode activé : Enregistre tous les événements (INFO, WARNING, ERROR)

🔍 Mode désactivé : Enregistre uniquement les avertissements et erreurs (WARNING, ERROR)

Quand l'activer ?

  • En phase de configuration : Pour vérifier que tout fonctionne correctement
  • En cas de problème : Pour diagnostiquer un dysfonctionnement
  • Pour le support : Si vous devez fournir des logs au support technique

⚠️ Impact sur les performances : Le mode détaillé génère beaucoup de logs et peut ralentir légèrement Thunderbird. Désactivez-le en utilisation normale.

Validation de l'UUID Send Later

Go2Econtact vérifie automatiquement que l'extension Send Later installée correspond bien à l'UUID officiel attendu.

✅ UUID attendu : sendlater3@kamens.us

🔒 Sécurité : Cette validation empêche l'utilisation d'extensions Send Later non officielles qui pourraient causer des conflits.

Messages d'erreur possibles :

  • "Send Later non détecté" : L'extension Send Later n'est pas installée
  • "UUID Send Later invalide" : L'extension Send Later installée n'a pas le bon UUID

💡 Solution : Installez l'extension officielle Send Later depuis addons.thunderbird.net

Actions disponibles

  • 💾 Enregistrer les modifications : Sauvegarde les paramètres modifiés
  • 🔄 Réinitialiser : Restaure les valeurs par défaut de l'onglet

⚠️ Enregistrement obligatoire : N'oubliez pas de cliquer sur "Enregistrer" après avoir modifié les paramètres, sinon vos changements seront perdus.

3. Onglet Comptes

Vue d'ensemble

L'onglet Comptes permet d'associer des templates d'AR à vos différents comptes email configurés dans Thunderbird. Chaque compte peut avoir son propre template et ses propres règles de filtrage.

📧 Comptes détectés : Go2Econtact détecte automatiquement tous les comptes email configurés dans Thunderbird.

Liste des comptes

Tous vos comptes email Thunderbird sont affichés dans un tableau avec les informations suivantes :

  • Compte : Nom du compte (ex: "Compte principal")
  • Adresse email : Adresse associée au compte
  • Template associé : Template actuellement sélectionné pour ce compte
  • Statut : Activé (✅) ou Désactivé (❌)
  • Actions : Boutons pour activer/désactiver ou configurer le compte

Association d'un template

Pour associer un template à un compte :

  1. Cliquez sur le bouton "⚙️ Configurer" du compte concerné
  2. Sélectionnez un template dans la liste déroulante
  3. Cliquez sur "Enregistrer"

⚠️ Template obligatoire : Un compte ne peut pas être activé sans template associé. Créez d'abord un template dans l'onglet Templates.

Activation / Désactivation d'un compte

Vous pouvez activer ou désactiver individuellement chaque compte via le bouton "Activer" ou "Désactiver".

✅ Compte activé : Go2Econtact traitera automatiquement les nouveaux emails reçus sur ce compte et enverra des AR selon les règles définies.

❌ Compte désactivé : Go2Econtact ignorera les emails reçus sur ce compte. Aucun AR ne sera envoyé.

Cas d'usage :

  • Activer uniquement votre compte professionnel pendant vos vacances
  • Désactiver temporairement un compte sans supprimer sa configuration
  • Tester l'extension sur un seul compte avant de l'activer sur tous

Gestion multi-comptes

Go2Econtact supporte la gestion de plusieurs comptes email avec des configurations distinctes :

💡 Exemple :

  • Compte pro : Template "Absence bureau" + Règles strictes (exclure newsletters)
  • Compte perso : Template "Absence vacances" + Règles souples
  • Compte association : Désactivé (pas d'AR sur ce compte)

Actions disponibles

  • ⚙️ Configurer : Associer un template au compte
  • ✅ Activer / ❌ Désactiver : Activer ou désactiver le traitement des emails pour ce compte
  • 💾 Enregistrer : Sauvegarder les modifications

Modification d'un template

  1. Dans la liste des templates, cliquez sur "✏️ Modifier"
  2. Effectuez vos modifications

⚠️ Impact sur les comptes : Si vous modifiez un template déjà associé à un compte actif, les nouveaux AR utiliseront immédiatement la version modifiée.

Suppression d'un template

  1. Cliquez sur "🗑️ Supprimer" à côté du template
  2. Confirmez la suppression

⚠️ Template en cours d'utilisation : Vous ne pouvez pas supprimer un template actuellement associé à un compte actif. Désactivez d'abord le compte ou associez-lui un autre template.

5. Onglet Règles de filtrage

Vue d'ensemble

L'onglet Règles de filtrage permet de définir précisément quels expéditeurs doivent recevoir un AR et lesquels doivent être exclus. C'est l'outil le plus puissant de Go2Econtact pour contrôler finement l'envoi d'AR.

🎯 Objectif : Envoyer des AR uniquement aux contacts pertinents (clients, partenaires, collègues externes) tout en excluant les newsletters, notifications automatiques et emails internes.

Types de règles

Go2Econtact propose deux types de règles :

✅ Règles d'inclusion : Définissent les expéditeurs qui DOIVENT recevoir un AR.

Exemple : Inclure tous les emails du domaine @client-important.com

❌ Règles d'exclusion : Définissent les expéditeurs qui NE DOIVENT PAS recevoir d'AR.

Exemple : Exclure tous les emails contenant "newsletter" dans le sujet

⚖️ Priorité : Les règles d'exclusion ont toujours la priorité sur les règles d'inclusion. Si un email correspond à une règle d'exclusion ET une règle d'inclusion, il sera exclu.

Critères de filtrage

Chaque règle peut être basée sur l'un des critères suivants :

  • 📧 Domaine expéditeur : Filtre basé sur le nom de domaine de l'adresse email
    • Exemple : gmail.com filtre tous les emails @gmail.com
  • 👤 Email expéditeur complet : Filtre basé sur l'adresse email complète
    • Exemple : noreply@entreprise.fr
  • 📝 Mot-clé dans le sujet : Filtre basé sur un mot ou une expression dans l'objet de l'email
    • Exemple : newsletter filtre tous les emails avec "newsletter" dans le sujet
  • 🔤 Mot-clé dans le corps : Filtre basé sur un mot ou une expression dans le contenu de l'email
    • Exemple : se désabonner filtre les emails contenant cette expression

Création d'une règle

  1. Cliquez sur "➕ Nouvelle règle"
  2. Sélectionnez le type de règle (Inclusion ou Exclusion)
  3. Choisissez le critère de filtrage (Domaine, Email, Sujet, Corps)
  4. Saisissez la valeur à filtrer (ex: newsletter)
  5. Optionnel : Ajoutez une description pour vous souvenir de l'objectif de la règle
  6. Cliquez sur "💾 Enregistrer"

✅ Règle créée : La règle est immédiatement active et sera appliquée aux prochains emails reçus.

Exemples de règles courantes

Exclusions recommandées

  • Newsletters : Exclure "newsletter" dans le sujet
  • Notifications automatiques : Exclure "noreply@" dans l'email
  • Réseaux sociaux : Exclure domaines facebook.com, linkedin.com, twitter.com
  • Emails internes : Exclure domaine @monentreprise.fr
  • Publicités : Exclure "promo", "offre", "soldes" dans le sujet
  • Services : Exclure "no-reply", "donotreply", "notification" dans l'email

Inclusions recommandées

  • Clients importants : Inclure domaine @client-vip.com
  • Partenaires : Inclure domaine @partenaire.fr
  • Contact spécifique : Inclure email chef@entreprise.fr

Modification / Suppression

  • ✏️ Modifier : Cliquez sur le bouton "Modifier" pour changer les paramètres d'une règle
  • 🗑️ Supprimer : Cliquez sur "Supprimer" pour retirer définitivement une règle

⚠️ Impact immédiat : Toute modification ou suppression de règle est immédiatement appliquée aux emails suivants.

Activation / Désactivation temporaire

Vous pouvez désactiver temporairement une règle sans la supprimer via le bouton "Activer/Désactiver".

💡 Astuce : Utile pour tester l'impact d'une règle ou pour la réactiver plus tard sans la recréer.

Ordre d'application des règles

Go2Econtact applique les règles dans l'ordre suivant :

  1. Vérification des règles d'exclusion : Si une règle d'exclusion correspond, l'AR n'est pas envoyé
  2. Vérification des règles d'inclusion : Si aucune règle d'inclusion n'est définie, l'AR est envoyé par défaut. Si des règles d'inclusion existent, l'email doit correspondre à au moins une règle pour envoyer l'AR
  3. Vérification des doublons : Si un AR a déjà été envoyé récemment à cet expéditeur, aucun AR n'est envoyé

💡 Stratégie recommandée : Commencez par définir les règles d'exclusion (ce que vous NE voulez PAS). Ajoutez ensuite des règles d'inclusion uniquement si vous voulez restreindre davantage.

Actions disponibles

  • ➕ Nouvelle règle : Créer une règle d'inclusion ou d'exclusion
  • ✏️ Modifier : Modifier les paramètres d'une règle
  • 🗑️ Supprimer : Supprimer définitivement une règle
  • ✅ Activer / ❌ Désactiver : Activer ou désactiver temporairement une règle
  • 💾 Enregistrer : Sauvegarder les modifications

6. Onglet Analyse

Vue d'ensemble

L'onglet Analyse permet de suivre en temps réel les décisions de filtrage prises par l'extension. Cette vue est idéale pour optimiser vos règles d'inclusion/exclusion.

📊 Objectif : Identifier les expéditeurs à exclure ou inclure selon la réalité des emails reçus.

Indicateurs résumés

Quatre indicateurs synthétiques sont affichés :

  • Événements traités : Nombre total d'emails analysés
  • AR créés : Nombre d'AR programmés pour envoi
  • Emails exclus : Nombre d'emails écartés par les règles
  • Doublons évités : Nombre d'emails déjà traités récemment

Filtres d'analyse

Vous pouvez filtrer les événements affichés selon plusieurs critères :

  • Période : Plage de dates (du... au...)
  • Décision : Type de décision (AR créé, Exclu, Doublon, Ignoré, Erreur)
  • Compte : Compte email concerné
  • Expéditeur : Recherche dans les adresses d'expéditeur

💡 Astuce : Utilisez les filtres pour identifier rapidement les emails d'un domaine spécifique ou analyser l'activité d'un compte particulier.

Tableau détaillé des événements

Chaque ligne du tableau représente un événement de traitement avec :

  • Date/Heure : Moment de traitement
  • Expéditeur : Adresse email de l'expéditeur
  • Compte : Compte destinataire
  • Sujet : Sujet du message
  • Décision : Action prise (avec code couleur)
  • Raison : Explication détaillée de la décision

Codes couleur des décisions :

  • AR créé (Vert) : L'AR a été programmé
  • Exclu (Rouge) : Email exclu par une règle
  • Doublon (Orange) : AR déjà envoyé récemment
  • Ignoré (Gris) : Email ignoré (email interne, pas de template, etc.)
  • Erreur (Rouge fond rose) : Erreur lors du traitement

Analyse détaillée

Deux vues synthétiques vous aident à optimiser vos règles :

Top 5 règles appliquées

Affiche les règles de filtrage les plus utilisées. Permet d'identifier les règles les plus pertinentes et celles à ajuster.

Top 5 domaines expéditeurs

Affiche les domaines qui envoient le plus d'emails. Utile pour décider si un domaine doit être exclu ou non.

💡 Utilité : Si un domaine apparaît souvent dans les AR créés mais ne devrait pas recevoir d'AR (ex: newsletters), ajoutez-le aux exclusions.

Actions disponibles

  • 🔄 Actualiser : Recharge les données d'analyse
  • 📤 Exporter CSV : Exporte les événements filtrés au format CSV
  • 🗑️ Effacer données : Supprime toutes les données d'analyse (irréversible)

⚠️ Export CSV : L'export prend en compte les filtres actifs. Pour exporter toutes les données, retirez tous les filtres avant d'exporter.

7. Logs de débogage

Vue d'ensemble

L'onglet Logs affiche l'historique des événements enregistrés par l'extension. Ces logs sont précieux pour diagnostiquer des problèmes ou comprendre le comportement de l'extension.

🔍 Utilité : Les logs détaillent chaque opération effectuée par l'extension (traitement des emails, validation UUID, envoi d'AR, etc.).

Niveaux de logging

L'extension utilise trois niveaux de logs :

  • INFO (Bleu) : Événements informatifs normaux (traitement d'email, AR programmé, etc.)
  • WARNING (Orange) : Avertissements (template vide, UUID manquant, doublon détecté, etc.)
  • ERROR (Rouge) : Erreurs critiques (échec connexion Send Later, erreur validation, etc.)

⚠️ Mode de logging : Par défaut, seuls les warnings et erreurs sont enregistrés. Pour voir tous les logs (y compris INFO), activez le mode logging détaillé dans l'onglet Général.

Consultation des logs

Les logs sont affichés dans un tableau avec les colonnes suivantes :

  • Date/Heure : Moment de l'événement
  • Niveau : INFO, WARNING ou ERROR (avec code couleur)
  • Catégorie : Module concerné (Background, Options, Template, etc.)
  • Message : Description détaillée de l'événement

💡 Astuce : Les logs les plus récents sont affichés en haut du tableau.

Filtres de logs

Vous pouvez filtrer les logs affichés selon :

  • Niveau : Afficher uniquement INFO, WARNING ou ERROR
  • Catégorie : Filtrer par module (Background, Template, etc.)
  • Recherche : Rechercher dans les messages

Actions disponibles

  • 🔄 Actualiser : Recharge les logs depuis la base de données
  • 📤 Exporter : Exporte les logs au format texte (utile pour le support)
  • 🗑️ Effacer l'historique : Supprime tous les logs (irréversible)

⚠️ Effacer les logs : Cette action est irréversible. Pensez à exporter vos logs avant si vous devez les conserver pour le support.

Utilisation pour le support

En cas de problème, les logs sont très utiles pour le support technique :

  1. Activez le mode logging détaillé (onglet Général)
  2. Reproduisez le problème
  3. Allez dans l'onglet Logs
  4. Exportez les logs au format texte
  5. Joignez le fichier de logs à votre demande de support

📧 Contact support : Pour toute question ou problème, contactez-moi à cette adresse : go2econtact@fip-toolkit.fr.
