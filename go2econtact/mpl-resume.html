Qu'est-ce que la MPL 2.0 ?

La Licence Publique Mozilla version 2.0 est une licence de logiciel libre. Elle définit les conditions dans lesquelles Go2Econtact peut être utilisé, modifié et redistribué. C'est une licence dite "copyleft modéré" : elle impose des obligations uniquement sur les fichiers que vous modifiez, pas sur l'ensemble de votre projet.

Ce que vous pouvez faire

  • Utiliser Go2Econtact librement, à titre personnel ou professionnel
  • Modifier le code source pour l'adapter à vos besoins
  • Redistribuer l'extension, modifiée ou non
  • Intégrer le code dans un projet plus large, y compris sous une autre licence

Ce que vous devez faire si vous modifiez le code

  • Conserver la licence MPL 2.0 dans les fichiers que vous avez modifiés
  • Rendre disponible le code source de ces fichiers modifiés
  • Indiquer clairement les modifications que vous avez apportées

Ces obligations ne s'appliquent qu'aux fichiers modifiés — pas à l'ensemble du projet dans lequel vous intégrez le code.

Ce que vous ne pouvez pas faire

  • Distribuer une version modifiée en gardant le code source secret
  • Supprimer les mentions de licence dans les fichiers d'origine
  • Utiliser le nom "Go2Econtact" pour désigner votre version modifiée
