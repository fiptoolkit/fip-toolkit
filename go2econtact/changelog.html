Historique des versions de Go2Econtact

Version 1.0

Actuelle

📅 15 novembre 2025

Première version publique de Go2Econtact - Extension Thunderbird pour l'automatisation des accusés de réception différés.

✨Fonctionnalités principales

  • Envoi automatique d'AR différés : Les accusés de réception sont envoyés après un délai configurable (1 à 24 heures) via l'extension Send Later
  • Templates multi-comptes : Gestion de templates d'AR personnalisés pour chaque compte de messagerie surveillé
  • Système de filtrage intelligent : Règles d'inclusion et d'exclusion par domaines, adresses email et patterns (avec support wildcards)
  • Mode test sécurisé : Testez votre configuration avec des délais réduits (2-10 minutes) avant la mise en production
  • Anti-doublons : Système intelligent pour éviter l'envoi de plusieurs AR au même expéditeur (fenêtre de 4 heures)
  • Statistiques d'utilisation : Suivez le nombre d'AR envoyés, les doublons évités et optimisez vos règles de filtrage
  • Analyse détaillée : Collecte de métriques pour optimiser les règles de filtrage
  • Système de mise à jour : Vérification automatique ou manuelle des nouvelles versions disponibles
  • Logs de débogage : Système de logging configurable (warnings/errors ou mode complet) pour faciliter le diagnostic
  • Interface intuitive : Système d'onglets avec validation visuelle (bordures colorées) pour guider la configuration

🔧Configuration requise

Prérequis obligatoires :
  • Thunderbird 128.0 ou version supérieure
  • Extension Send Later (v9.0+) installée et configurée

Note importante : Sans Send Later, Go2Econtact ne peut pas fonctionner. Send Later gère l'envoi effectif des messages différés tandis que Go2Econtact automatise la création des accusés de réception.

📌Notes importantes

  • Environnement cible : Conçu pour des environnements professionnels avec boîtes IMAP partagées
  • Configuration UUID Send Later : L'UUID d'instance de Send Later doit être configuré manuellement dans l'onglet "Send Later"
  • Domaine interne : Les emails internes (même domaine) sont exclus automatiquement des AR
  • Suppression des AR envoyés : Par défaut, les AR envoyés sont automatiquement supprimés du dossier "Éléments envoyés"
  • Intervalle de vérification : Les nouveaux emails sont vérifiés toutes les 5 minutes par défaut

🗂️Architecture technique

Go2Econtact est structuré en modules fonctionnels :

  • background.js : Cœur algorithmique et logique métier principale
  • config.js : Configuration centralisée et constantes
  • popup : Interface rapide de vérification Send Later
  • options : Interface de configuration complète avec modules spécialisés

🧩Modules fonctionnels

  • template-editor.js : Gestion multi-comptes avec templates personnalisés
  • statistics.js : Métriques d'utilisation et export CSV
  • analysis.js : Collecte détaillée pour optimiser règles filtrage
  • update-manager.js : Vérification des mises à jour (format Mozilla standard)
  • logs-viewer.js : Affichage et gestion des logs de débogage
