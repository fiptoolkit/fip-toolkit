⚙️ Onglet Général

C'est l'onglet central de Go2Econtact. Il regroupe tout ce qui concerne le comportement de l'extension : qui reçoit un accusé de réception, dans quelles conditions, et comment l'extension réagit en cas de situation particulière.

Paramètres généraux

  • Domaine interne — Saisissez le domaine de votre organisation (ex : societe.fr). Les emails provenant de ce domaine ne recevront jamais d'accusé de réception, sauf exception définie dans les Inclusions.
  • Délai d'envoi — Temps d'attente avant l'envoi de l'accusé de réception. Valeur par défaut : 2 heures (recommandé). Plage disponible : 1 à 24 heures.

Filtrage — Exclusions

Les exclusions définissent qui ne recevra jamais d'accusé de réception. Quatre types de règles sont disponibles, à saisir une par ligne :

  • Sujets — filtre sur l'objet du message reçu. Trois formes disponibles, insensibles à la casse :
    [COMMENCE]Re: — l'objet commence par "Re:"
    [CONTIENT]absence — l'objet contient le mot "absence"
    [FINIT]automatique — l'objet se termine par "automatique"
  • Domaines — tous les emails d'un domaine entier. Exemple : @spam.com exclut tout le monde chez spam.com.
  • Adresses — une adresse email exacte à exclure.
  • Filtres automatiques — avec le caractère joker *. Exemple : noreply@* exclut d'un seul coup tous les expéditeurs "noreply", quel que soit leur domaine — noreply@banque.fr, noreply@client.com, noreply@fournisseur.fr, etc. Le bouton Ajouter les filtres par défaut insère les plus courants d'un seul clic.
Les boutons Assistant et Tester ouvrent directement les outils interactifs du site d'aide pour créer ou vérifier vos règles sans risque. Le bouton Importer charge un fichier de règles de filtrage préparé par l'Assistant du site d'aide (règles uniquement, pas la configuration complète).

Filtrage — Inclusions

Les inclusions fonctionnent à l'inverse : elles forcent l'envoi d'un accusé de réception, même si l'expéditeur figure dans les exclusions. Les inclusions ont toujours la priorité absolue.

Exemple d'usage : votre domaine interne est exclu par défaut, mais un collaborateur précis doit tout de même recevoir un AR — ajoutez son adresse dans les inclusions.

Surveillance des emails

  • Comptes surveillés — un résumé affiche le nombre de comptes configurés et actifs. Le bouton Gérer les comptes et modèles renvoie directement vers l'onglet Modèles.
  • Dossiers personnalisés — si vos emails externes arrivent dans un dossier autre que la Boîte de réception, indiquez son nom ici (un par ligne). Exemple : courriel externe, courriel interne
  • Supprimer les AR du dossier Envoyés — activée par défaut, cette option supprime automatiquement l'accusé de réception de votre dossier Envoyés après son expédition, pour ne pas l'encombrer.

Mode test

Quand cette case est cochée, Go2Econtact n'envoie des accusés de réception qu'à une seule adresse — celle que vous indiquez. Tous les autres emails sont ignorés.

C'est la façon la plus sûre de vérifier que tout fonctionne avant de passer en utilisation réelle : envoyez-vous un email depuis l'adresse de test, et vérifiez que vous recevez bien l'accusé de réception.

Avant de décocher le mode test, vérifiez que vos exclusions sont bien configurées — une fois désactivé, tous les emails externes éligibles recevront un accusé de réception automatiquement.

Paramètres avancés

Ces réglages n'ont pas besoin d'être modifiés en utilisation normale. Touchez-y uniquement si vous observez des dysfonctionnements.

  • Fenêtre anti-doublons — durée pendant laquelle Go2Econtact se souvient d'avoir déjà envoyé un AR à un expéditeur. Défaut : 4 heures (plage : 1 à 48h). Cela évite d'envoyer plusieurs AR à la même personne si elle vous écrit plusieurs fois dans la journée.
  • Intervalle de surveillance — fréquence à laquelle Go2Econtact vérifie l'arrivée de nouveaux messages. Défaut : 5 minutes (plage : 1 à 60 min).
  • Nombre de tentatives — si un message tarde à apparaître côté serveur, combien de fois réessayer avant d'abandonner. Défaut : 5. Augmentez si votre serveur de messagerie est lent.
  • Délais d'attente — temps de pause entre chaque tentative, séparément pour le dossier Brouillons et le dossier Envoyés. Défaut : 1 seconde chacun.
  • Enregistrement complet des traces — active un journal détaillé de toutes les opérations. Utile pour diagnostiquer un problème, à désactiver ensuite.
  • Nom pour les exports — nom qui apparaîtra dans les fichiers exportés depuis l'onglet Statistiques. Laissez vide pour la détection automatique.

Gestion de la configuration

Deux boutons permettent de sauvegarder ou de restaurer l'ensemble de votre configuration dans un fichier :

  • Exporter la configuration — crée un fichier de sauvegarde complet (filtrage, surveillance, paramètres avancés) que vous pouvez conserver ou transmettre.
  • Importer une configuration — restaure une configuration exportée précédemment. Une fenêtre de confirmation s'affiche avant l'import.
Important : le code d'identification Send Later est propre à chaque poste de travail. Si vous importez une configuration sur un autre poste, pensez à mettre à jour ce code dans l'onglet Send Later.
N'oubliez pas de cliquer sur Enregistrer la configuration en bas de l'onglet après toute modification.
