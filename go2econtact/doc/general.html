Onglet Configuration

C'est l'onglet central de Go2Econtact. Il regroupe tout ce qui concerne le comportement de l'extension : qui reçoit un accusé de réception, dans quelles conditions, et comment l'extension réagit en cas de situation particulière.

Paramètres généraux

  • Domaines internes — Saisissez un ou plusieurs domaines de votre organisation, un par ligne (ex : societe.fr, *.filiale.fr). Les courriels provenant de ces domaines ne recevront jamais d'accusé de réception, sauf exception définie dans les Inclusions.
  • Délai d'envoi de l'AR — Temps d'attente avant l'envoi de l'accusé de réception. Valeur par défaut : 1 heure (recommandé). Choix proposés : de 1 à 24 heures. En mode test, ce délai se règle en minutes.

Filtrage — Exclusions

Les exclusions définissent qui ne recevra jamais d'accusé de réception. Cinq types de règles sont disponibles, à saisir une par ligne :

  • Sujets — filtre sur l'objet du message reçu. Trois formes disponibles, insensibles à la casse :
    [COMMENCE]Re: — l'objet commence par "Re:"
    [CONTIENT]absence — l'objet contient le mot "absence" ou "ABSENCE"
    [FINIT]automatique — l'objet se termine par "automatique" ou "Automatique"
  • Domaines — tous les courriels d'un domaine entier. Notation : societe.fr = domaine exact, *.societe.fr = sous-domaines uniquement, *.fr = tous les sous-domaines .fr, * = absolument tous. Exemple : *.spam.com exclut les sous-domaines de spam.com (ex. mail.spam.com) — pas spam.com lui-même, qu'il faut ajouter séparément si vous voulez aussi le bloquer.
  • Adresses — une adresse courriel exacte à exclure.
  • Patterns exclus (filtres automatiques) — avec le caractère joker *. Exemple : noreply@* exclut d'un seul coup tous les expéditeurs "noreply", quel que soit leur domaine — noreply@banque.fr, noreply@client.com, noreply@fournisseur.fr, etc. Le bouton Ajouter les patterns par défaut insère les plus courants d'un seul clic.
  • Domaines ou pays entièrement bloqués — bloque complètement un domaine ou un pays, y compris l'adresse principale elle-même (pas seulement ses sous-domaines). Exemple : gouv.fr bloque aussi bien gouv.fr que mail.gouv.fr. N'utilisez pas d'étoile (*) ici — un suffixe exact uniquement.
Les boutons Assistant et Tester ouvrent directement les outils interactifs du site d'aide pour créer ou vérifier vos règles sans risque. Le bouton Importer charge un fichier de règles de filtrage préparé par l'Assistant du site d'aide (règles uniquement, pas la configuration complète).

Filtrage — Inclusions

Les inclusions fonctionnent à l'inverse : elles forcent l'envoi d'un accusé de réception, même si l'expéditeur figure dans les exclusions. Les inclusions ont toujours la priorité absolue.

Exemple d'usage : votre domaine interne est exclu par défaut, mais un collaborateur précis doit tout de même recevoir un AR — ajoutez son adresse dans les inclusions.

Surveillance des emails

  • Comptes surveillés — un résumé affiche le nombre de comptes configurés, ceux qui sont actifs (un modèle est défini) et ceux qui ne sont pas surveillés. Chaque compte apparaît sous forme de fiche, Actif ou Inactif. Un compte sans modèle reste inactif : aucun AR n'y est créé. Le bouton Gérer les comptes et modèles renvoie directement vers l'onglet Modèles.
  • Dossiers supplémentaires surveillés — la Boîte de réception est toujours surveillée. Si vos courriels externes arrivent aussi dans un autre dossier (par exemple un dossier alimenté par une règle de tri), ouvrez la fiche du compte et cliquez sur + Ajouter un dossier. Les dossiers système (Envoyés, Brouillons, Corbeille…) ne peuvent pas être ajoutés ; 20 dossiers au maximum par compte.
  • Supprimer les AR du dossier Envoyés après envoi — activée par défaut, cette option supprime automatiquement l'accusé de réception de votre dossier Envoyés après son expédition, pour ne pas l'encombrer.

Mode test

Quand cette case est cochée, Go2Econtact n'envoie des accusés de réception qu'à une seule adresse — celle que vous indiquez. Tous les autres courriels sont ignorés.

En mode test, le délai d'envoi se règle en minutes (de 2 à 10, 2 par défaut) pour que vous n'attendiez pas des heures. Un seul AR est créé toutes les 5 minutes pour une même adresse.

C'est la façon la plus sûre de vérifier que tout fonctionne avant de passer en utilisation réelle : envoyez-vous un courriel depuis l'adresse de test, et vérifiez que vous recevez bien l'accusé de réception.

Avant de décocher le mode test, vérifiez que vos exclusions sont bien configurées — une fois désactivé, tous les courriels externes éligibles recevront un accusé de réception automatiquement.

Paramètres avancés

Ces réglages n'ont pas besoin d'être modifiés en utilisation normale. Touchez-y uniquement si vous observez des dysfonctionnements.

  • Fenêtre de vérification des doublons — utile surtout si Go2Econtact tourne sur plusieurs ordinateurs avec la même boîte : avant de créer un AR, l'extension vérifie qu'un autre poste n'en a pas déjà programmé un pour le même expéditeur et le même sujet. Défaut : 4 heures (plage : 1 à 48 h). Par ailleurs, un expéditeur ne reçoit jamais plus d'un AR par jour de la part d'un même poste.
  • Délai de vérification différée — parfois, le serveur de messagerie est lent et l'AR qui vient d'être préparé n'est pas encore visible dans les Brouillons. Go2Econtact refait alors une vérification plus tard, avant l'envoi, pour s'assurer que tout est en ordre (le même délai sert à un second essai de nettoyage du dossier Envoyés). Laissez le champ vide : le délai est alors calculé automatiquement (recommandé). Sinon, indiquez une valeur de 15 à 60 minutes ; un texte sous le champ précise la valeur réellement retenue. Sans effet en mode test.
  • Nombre de tentatives — si un message tarde à apparaître côté serveur, combien de fois réessayer avant d'abandonner. Défaut : 5. Augmentez si votre serveur de messagerie est lent.
  • Délais d'attente — temps de pause entre chaque tentative, séparément pour le dossier Brouillons et le dossier Envoyés. Défaut : 2 secondes chacun.
  • Délai de synchronisation IMAP — pause laissée au serveur pour se synchroniser avant la recherche. Défaut : 5 secondes ; augmentez si votre serveur est lent.
  • Activer l'enregistrement de tous les logs — active un journal détaillé de toutes les opérations. Utile pour diagnostiquer un problème, à désactiver ensuite.
  • Nom utilisateur pour les fichiers CSV — nom qui apparaîtra dans les fichiers exportés (statistiques, analyse, configuration). Laissé vide : « Utilisateur-Inconnu ».
  • Exporter automatiquement après chaque enregistrement — à chaque clic sur Enregistrer la configuration, une copie du fichier de configuration est téléchargée.

Gestion de la configuration

Deux boutons permettent de sauvegarder ou de restaurer l'ensemble de votre configuration dans un fichier :

  • Exporter configuration — crée un fichier de sauvegarde complet (filtrage, surveillance, paramètres avancés) que vous pouvez conserver ou transmettre.
  • Importer configuration — restaure une configuration exportée précédemment. Une fenêtre de confirmation s'affiche avant l'import ; si le fichier contient l'identifiant Envoyer Plus Tard, elle vous demande de confirmer son remplacement.
Important : le code d'identification de Envoyer plus tard (instanceUUID) est propre à chaque poste de travail. Si vous importez une configuration sur un autre poste, pensez à mettre à jour ce code dans l'onglet Envoyer Plus Tard.
N'oubliez pas de cliquer sur Enregistrer la configuration en bas de l'onglet après toute modification.
