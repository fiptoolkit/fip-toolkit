✉️ Onglet Modèles

C'est ici que vous rédigez le message qui sera envoyé automatiquement à vos correspondants. Chaque adresse email que vous gérez dans Thunderbird peut avoir son propre message — ou aucun, si vous ne souhaitez pas d'accusé de réception pour cette adresse.

Choisir l'adresse à configurer

La liste déroulante en haut de l'onglet affiche tous vos comptes Thunderbird. Sélectionnez celui que vous souhaitez configurer : l'éditeur se met à jour en conséquence.

Un indicateur sous la liste vous indique si ce compte a déjà un message configuré ou non.

Rédiger le message

Le message est saisi en HTML directement dans la zone de texte. Si vous n'êtes pas à l'aise avec le HTML, utilisez le bouton Charger défaut : il insère un message prêt à l'emploi que vous pouvez personnaliser librement.

Le bouton Aperçu affiche le rendu visuel du message en temps réel, tel qu'il apparaîtra dans la boîte de réception de vos correspondants.

Besoin d'aide pour créer votre message ?

Si vous partez de zéro, deux outils gratuits en ligne permettent de concevoir un message visuellement — sans toucher au code — puis d'en récupérer le HTML à coller dans l'éditeur :

  • Stripo — éditeur glisser-déposer, plan gratuit sans limite de durée, export HTML direct. Interface disponible en français.
  • Beefree — pas de compte requis pour concevoir, compte requis uniquement à l'export (6 exports gratuits par mois). HTML propre et sobre.

Une fois votre message conçu, exportez-le en HTML puis importez-le dans Go2Econtact via le bouton Importer un modèle.

Actions disponibles

  • Sauvegarder — enregistre le message pour ce compte
  • Effacer — vide l'éditeur (le compte n'enverra plus d'accusé de réception)
  • Charger défaut — insère le message type fourni avec l'extension
  • Exporter le modèle — sauvegarde le message dans un fichier pour le partager ou le sauvegarder
  • Dupliquer vers… — copie le message vers un autre compte de la liste
  • Importer un modèle — charge un message depuis un fichier exporté précédemment
  • Retirer de la configuration — supprime ce compte de la liste de suivi

Tableau récapitulatif

En bas de l'onglet, un tableau liste tous vos comptes configurés avec la date de dernière modification. Cliquez sur une ligne pour éditer directement ce compte.

À retenir : un compte sans message ne recevra aucun accusé de réception, même s'il est présent dans Thunderbird. C'est le moyen le plus simple de désactiver les AR pour une adresse spécifique.
