🔗 Onglet Envoyer Plus Tard

Go2Econtact ne peut pas envoyer lui-même des messages : il délègue cet envoi à une autre extension Thunderbird appelée Send Later. C'est elle qui se charge de mettre le message d'accusé de réception en attente et de l'expédier au moment voulu.

Pour que les deux extensions se reconnaissent, Go2Econtact a besoin d'un code d'identification propre à votre installation de Send Later. Ce code est généré automatiquement par Send Later lors de son installation — il est donc unique à votre poste.

Où trouver ce code ?

  1. Dans Thunderbird, ouvrez le menu Modules complémentaires et thèmes
  2. Repérez l'extension Envoyer Plus Tard et cliquez sur son icône pour accéder à ses options
  3. Vérifiez que l'onglet Options est bien sélectionné, puis faites défiler la liste jusqu'à la section Avancé
  4. Cliquez sur Éditeur de configuration avancé pour déplier la liste des paramètres, puis faites défiler jusqu'à la ligne instanceUUID
  5. Sélectionnez l'identifiant complet accolades comprises à la souris, puis copiez-le (Ctrl+C)

Saisir le code dans Go2Econtact

  1. Dans l'onglet Envoyer Plus Tard de Go2Econtact, collez le code dans le champ prévu
  2. Un indicateur passe au vert ✓ si le code est reconnu comme valide — il est enregistré automatiquement
  3. S'il reste rouge ✗, vérifiez que vous avez bien copié l'intégralité du code, accolades incluses
À savoir : si vous désinstallez puis réinstallez Send Later, un nouveau code sera généré. Il faudra alors revenir ici pour le mettre à jour.
