Onglet Logs

Le journal enregistre les événements techniques survenus pendant le fonctionnement de Go2Econtact. Il est principalement utile pour comprendre pourquoi quelque chose ne s'est pas passé comme prévu.

Ce que contient le journal

Trois niveaux d'entrées sont enregistrés, reconnaissables à leur couleur :

  • Information — déroulement normal des opérations (visible uniquement si l'option « Activer l'enregistrement de tous les logs » est cochée dans l'onglet Configuration, section Paramètres avancés)
  • Avertissement — situation inhabituelle mais non bloquante
  • Erreur — problème ayant empêché une opération de se terminer normalement

Le journal conserve les 50 dernières entrées. Les plus anciennes sont effacées automatiquement au-delà de cette limite.

Filtrer les entrées

Trois choix permettent d'afficher toutes les entrées, uniquement les erreurs, ou uniquement les avertissements : « Tous les logs », « Erreurs uniquement » et « Avertissements » — pratique pour aller droit à l'essentiel.

Actions

  • Actualiser — recharge la liste des entrées
  • Copier — copie le contenu du journal dans le presse-papier pour le coller dans un courriel de support
  • Télécharger — enregistre le journal dans un fichier texte
  • Vider — efface toutes les entrées
En cas de problème inexpliqué, activez l'option Activer l'enregistrement de tous les logs dans l'onglet Configuration (Paramètres avancés), reproduisez le problème, puis revenez ici consulter les nouvelles entrées. Pensez à la désactiver une fois le diagnostic terminé.
