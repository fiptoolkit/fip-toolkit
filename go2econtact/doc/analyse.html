🔍 Onglet Analyse

Là où l'onglet Statistiques donne des chiffres globaux, l'onglet Analyse descend au niveau de chaque email reçu. Pour chaque message, vous voyez la décision prise par Go2Econtact et la règle qui l'a motivée. Données conservées sur les 15 derniers jours.

Le tableau des événements

Chaque ligne correspond à un email reçu, avec les colonnes suivantes :

  • Date/Heure — quand le message a été reçu
  • Expéditeur — adresse de l'envoyeur
  • Décision — ce que Go2Econtact a fait : AR créé, Exclu, Inclus (forcé), Doublon évité ou Ignoré
  • Règle appliquée — la règle précise qui a déclenché cette décision
  • Sujet — l'objet de l'email reçu
📸 Capture d'écran — tableau d'analyse avec décisions colorées

Filtres

Le tableau peut être filtré par période, par expéditeur (recherche libre), par type de décision ou par type d'événement (message nouveau ou déplacé). Combinez les filtres pour isoler rapidement un expéditeur ou comprendre pourquoi un AR n'a pas été envoyé.

Analyse détaillée

Deux listes complètent le tableau :

  • Top 5 règles appliquées — les règles qui se déclenchent le plus souvent, utiles pour affiner vos exclusions
  • Top 5 domaines expéditeurs — les domaines les plus actifs dans votre boîte

Actions

  • Actualiser — recharge les données depuis le dernier démarrage de Thunderbird
  • Exporter CSV — sauvegarde le tableau filtré dans un fichier tableur
  • Effacer données — supprime l'historique d'analyse
