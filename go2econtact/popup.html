📱 Interface Popup

Contrôle rapide et planification de Go2Econtact

L'interface popup est le point d'entrée principal de Go2Econtact. Accessible en cliquant sur l'icône de l'extension dans Thunderbird, elle vous permet de contrôler l'activation, consulter le statut et gérer la planification hebdomadaire.

🎯 Accès rapide

Comment ouvrir le popup :

Cliquez sur l'icône 📧⏰ de Go2Econtact dans la barre d'outils de Thunderbird

⚙️ Paramètres

Bouton visible immédiatement en haut du popup pour accéder à la configuration complète de l'extension.

✓ Statut Send Later

Vérification automatique de la présence et de l'activation de l'extension Send Later (prérequis obligatoire).

🔄 Toggle activation/désactivation

⚠️ Important : Ce toggle est éphémère (non persistant)

L'extension se réactivera automatiquement au prochain démarrage de Thunderbird

Fonctionnement

Le toggle permet de stopper temporairement la création d'accusés de réception pendant la session en cours, sans modifier votre configuration.

✓ Extension active

Toggle coché : Go2Econtact surveille les emails et crée des AR différés selon votre configuration

✗ Extension inactive

Toggle décoché : Aucun AR ne sera créé jusqu'à réactivation manuelle ou redémarrage de Thunderbird

💡 Cas d'usage :

• Pause temporaire pendant une maintenance

• Test de configuration sans créer d'AR

• Désactivation rapide en cas d'urgence

📅 Planification - Aujourd'hui

La section Aujourd'hui affiche le statut de la planification pour la journée en cours et permet un ajustement ponctuel sans modifier la planification hebdomadaire.

Affichage du statut

Le popup affiche le jour de la semaine et le mode de fonctionnement prévu :

  • ✓ ON toute la journée : L'extension fonctionne en continu
  • ✗ OFF toute la journée : L'extension est désactivée pour la journée
  • ⏰ OFF automatique prévu à [heure] : L'extension s'arrêtera automatiquement à l'heure configurée

Bouton "🔧 Ajuster pour aujourd'hui"

Permet de modifier ponctuellement le comportement pour la journée en cours sans toucher à la planification hebdomadaire.

Mode édition

3 boutons de mode :

• ✓ ON toute la journée

• ✗ OFF toute la journée

• ⏰ OFF automatique + sélecteur d'heure

Validation

✓ Valider : Applique l'ajustement pour aujourd'hui uniquement

✗ Annuler : Ferme le mode édition sans modification

⚠️ Ajustement temporaire :

Les modifications apportées via "Ajuster pour aujourd'hui" ne sont valables que pour la journée en cours. Demain, la planification hebdomadaire reprendra normalement.

📆 Planification hebdomadaire

La section Planification hebdomadaire est collapsible (repliable) et permet de configurer le comportement de l'extension pour chaque jour de la semaine.

Activation/Désactivation du planificateur

Toggle "Activé/Désactivé" :

• Activé : La planification hebdomadaire est appliquée automatiquement

• Désactivé : L'extension fonctionne en continu (pas d'arrêt automatique)

Configuration par jour

Chaque jour de la semaine dispose de 3 modes de fonctionnement :

✓ ON toute la journée

L'extension fonctionne en continu du lundi au vendredi. Le sélecteur d'heure est désactivé.

✗ OFF toute la journée

L'extension est désactivée pour la journée (typiquement samedi/dimanche). Le sélecteur d'heure est désactivé.

⏰ OFF automatique

L'extension s'arrête automatiquement à l'heure configurée. Le toggle passe à OFF à cette heure, vous pouvez le réactiver manuellement si besoin.

Exemple de configuration

Configuration typique bureau 9h-17h :

  • Lundi à Jeudi : ⏰ OFF automatique à 17:00
  • Vendredi : ⏰ OFF automatique à 16:00
  • Samedi et Dimanche : ✓ ON toute la journée (pas de bureau, AR acceptables)

ℹ️ Note importante :

Le toggle passera automatiquement à OFF à l'heure programmée. Vous pourrez le réactiver manuellement si vous devez traiter des emails après l'heure de coupure prévue.

Sauvegarde de la planification

Après avoir configuré vos jours de la semaine, cliquez sur 💾 Enregistrer la planification pour valider et activer votre configuration.

⚠️ Validation requise :

Les modifications ne sont pas appliquées tant que vous n'avez pas cliqué sur "Enregistrer la planification"

🎯 Workflow recommandé

Première utilisation :

  1. Ouvrir le popup et vérifier que Send Later est détecté (statut ✓)
  2. Cliquer sur ⚙️ Paramètres pour accéder à la configuration complète
  3. Configurer les templates, règles de filtrage et comptes surveillés
  4. Revenir au popup et configurer la planification hebdomadaire
  5. Vérifier que le toggle est activé (✓)

💡 Utilisation quotidienne :

• Ouvrir le popup pour vérifier le statut du jour

• Utiliser "Ajuster pour aujourd'hui" si besoin ponctuel

• Désactiver temporairement via le toggle si nécessaire
