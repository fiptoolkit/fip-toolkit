Go2Econtact — réponses aux questions courantes

Vous ne trouvez pas votre réponse ici ? Consultez la documentation ou le tutoriel.

Démarrage

Go2Econtact fonctionne-t-il sans Send Later ?

Non. Send Later est indispensable — c'est elle qui gère l'envoi différé des accusés de réception. Sans elle, Go2Econtact ne peut pas fonctionner.

Send Later doit être installée en version 9.0 ou supérieure et activée dans Thunderbird.

Comment accéder à la configuration ?

Deux façons :

  • Cliquez sur l'icône Go2Econtact dans Thunderbird, puis sur Paramètres
  • Ou : clic droit sur l'icône → Options
Puis-je l'utiliser avec plusieurs adresses courriel ?

Oui. Chaque adresse gérée dans Thunderbird peut avoir son propre modèle de message. Une adresse sans modèle configuré ne génèrera aucun accusé de réception.

La configuration se fait dans l'onglet Modèles.

Utilisation

Comment activer ou désactiver rapidement l'extension ?

Cliquez sur l'icône Go2Econtact dans Thunderbird : le popup affiche un bouton bascule en haut. Décochez-le pour suspendre l'envoi des accusés de réception.

À savoir : cette désactivation est temporaire — elle ne concerne que la session en cours. Au prochain démarrage de Thunderbird, l'extension se réactive automatiquement.
Les courriels internes de mon organisation reçoivent-ils un accusé de réception ?

Non, si vous avez renseigné votre domaine interne dans l'onglet Général (champ "Domaine interne"). Tous les courriels provenant de ce domaine sont automatiquement exclus.

Si une adresse interne doit tout de même recevoir un AR, ajoutez-la dans les Inclusions — elles ont la priorité absolue.

Comment éviter d'envoyer des AR aux newsletters et courriels automatiques ?

Utilisez les Exclusions dans l'onglet Général :

  • Par filtre automatique — noreply@* exclut tous les expéditeurs "noreply" quel que soit leur domaine. Le bouton Ajouter les filtres par défaut insère les plus courants d'un clic.
  • Par sujet — [CONTIENT]newsletter exclut tous les courriels dont l'objet contient ce mot.
  • Par domaine — excluez directement le domaine de l'expéditeur.

Le Simulateur permet de tester vos règles avant de les appliquer.

Un même expéditeur peut-il recevoir plusieurs accusés de réception ?

Pas si la personne vous écrit plusieurs fois dans la même journée. Go2Econtact mémorise les expéditeurs ayant déjà reçu un AR et n'en envoie pas un second pendant 4 heures (réglage par défaut, modifiable dans les Paramètres avancés).

Au-delà de cette fenêtre, un nouvel AR sera envoyé normalement.

Problèmes courants

L'extension ne se charge pas ou ne s'affiche pas

Vérifiez dans cet ordre :

  • Thunderbird est en version 115 ou supérieure
  • Go2Econtact est bien activée dans Modules complémentaires
  • Redémarrez complètement Thunderbird
  • Si le problème persiste, désactivez temporairement les autres extensions pour isoler un éventuel conflit
Erreur "Send Later introuvable"

Go2Econtact ne détecte pas Send Later. Vérifiez :

  • Send Later est installée et activée dans Modules complémentaires
  • La version installée est 9.0 ou supérieure
  • Thunderbird a été redémarré après l'installation de Send Later
Les accusés de réception partent immédiatement au lieu d'être différés

Cause la plus fréquente : le code d'identification Send Later est incorrect. Vérifiez dans l'onglet Send Later que l'indicateur est bien au vert ✓.

Si le code est correct, vérifiez dans les préférences de Send Later qu'aucun délai à zéro n'est configuré.

Comportement normal : l'accusé de réception doit apparaître dans le dossier Brouillons de Send Later, puis partir après le délai configuré (2 heures par défaut).
