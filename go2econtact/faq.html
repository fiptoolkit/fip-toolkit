Vous trouverez ci-dessous les réponses aux questions les plus fréquemment posées sur Go2Econtact. Si votre question ne figure pas dans cette liste, consultez la documentation complète ou le tutoriel de configuration.

Installation et configuration

Comment installer Go2Econtact ?

Go2Econtact est une extension pour Thunderbird. Voici comment l'installer :

  • Téléchargez le fichier .xpi depuis le site officiel
  • Dans Thunderbird, allez dans Modules complémentaires et thèmes (menu hamburger ☰ → Modules complémentaires)
  • Cliquez sur l'icône ⚙️ (engrenage) → Installer un module depuis un fichier
  • Sélectionnez le fichier .xpi téléchargé
  • Confirmez l'installation et redémarrez Thunderbird si nécessaire

ℹ️ Prérequis : Thunderbird 128.0 ou supérieur est requis.

Ai-je besoin d'autres extensions pour que Go2Econtact fonctionne ?

Oui, Go2Econtact nécessite l'extension Send Later pour programmer l'envoi différé des accusés de réception.

  • Send Later doit être installé et activé dans Thunderbird
  • Version minimale requise : Send Later 9.0 ou supérieur
  • Téléchargement : addons.thunderbird.net

🚨 Important : Sans Send Later, Go2Econtact ne pourra pas programmer l'envoi différé des AR et affichera une erreur.

Comment accéder à l'interface de configuration ?

Une fois Go2Econtact installé, vous pouvez accéder à son interface de configuration de deux façons :

  • Via le menu Thunderbird : Outils → Go2Econtact
  • Via les modules complémentaires : Menu ☰ → Modules complémentaires → Go2Econtact → Options

✓ Raccourci : L'interface s'ouvre dans un nouvel onglet de Thunderbird pour un accès facile.

Quels sont les paramètres minimaux pour démarrer ?

Pour que Go2Econtact fonctionne, vous devez au minimum :

  • Créer un template dans l'onglet Templates (message d'absence)
  • Associer ce template à un compte dans l'onglet Comptes
  • Activer le compte concerné

Les autres paramètres (délai d'envoi, règles de filtrage, etc.) peuvent être configurés ultérieurement selon vos besoins.

💡 Conseil : Consultez le tutoriel de configuration pour un guide pas à pas.

Comment configurer facilement mes règles sans formation technique ?

Go2Econtact propose deux outils interactifs pour vous aider à configurer vos règles d'accusés de réception :

  • 🧙‍♂️ Assistant de configuration - Un guide pas-à-pas en 4 étapes qui vous accompagne dans la création de votre configuration. Idéal pour débuter sans formation technique.
  • 🔬 Simulateur de règles - Un outil qui vous permet de tester vos règles en temps réel. Vous saisissez une adresse email et le simulateur vous indique immédiatement si elle recevra ou non un accusé de réception.

Ces outils sont accessibles directement depuis la page d'accueil de Go2Econtact.

✓ Recommandé : Utilisez d'abord l'assistant pour créer votre configuration, puis le simulateur pour la tester avant de l'importer dans Thunderbird.

Puis-je utiliser Go2Econtact avec plusieurs comptes email ?

Oui ! Go2Econtact supporte la gestion de plusieurs comptes email simultanément.

  • Chaque compte peut avoir son propre template d'AR
  • Chaque compte peut être activé/désactivé indépendamment
  • Les règles de filtrage s'appliquent à tous les comptes actifs

💡 Exemple : Vous pouvez activer Go2Econtact uniquement sur votre compte professionnel pendant vos vacances, tout en gardant votre compte personnel inactif.

Comment vérifier que Send Later est correctement configuré ?

Go2Econtact valide automatiquement la présence de Send Later au démarrage. Pour vérifier manuellement :

  • Allez dans l'onglet Général de Go2Econtact
  • Vérifiez le statut de l'UUID Send Later (doit afficher sendlater3@kamens.us)
  • Si l'UUID est incorrect ou absent, réinstallez Send Later

🚨 Erreur UUID : Si l'UUID ne correspond pas, Go2Econtact refusera de programmer des AR pour éviter les conflits.

Utilisation

Comment activer/désactiver rapidement l'extension ?

Pour activer ou désactiver Go2Econtact pour un compte spécifique :

  • Allez dans l'onglet 👥 Comptes
  • Cliquez sur le bouton "Activer" ou "Désactiver" du compte concerné
  • Les changements sont immédiats (pas besoin de redémarrer Thunderbird)

✓ Astuce : Désactivez temporairement un compte si vous êtes disponible et voulez répondre manuellement aux emails.

Que se passe-t-il quand je reçois un nouvel email ?

Voici le processus complet :

  • 1. Réception : Thunderbird reçoit un nouvel email
  • 2. Analyse : Go2Econtact vérifie si le compte destinataire est actif
  • 3. Filtrage : Les règles d'inclusion/exclusion sont appliquées
  • 4. Détection doublons : Vérification si un AR a déjà été envoyé récemment à cet expéditeur
  • 5. Génération AR : Si toutes les conditions sont remplies, un AR est généré à partir du template
  • 6. Programmation : L'AR est transmis à Send Later pour envoi différé

📊 Suivi : Consultez l'onglet Analyse pour voir les décisions prises en temps réel.

Comment empêcher l'envoi d'AR aux newsletters ?

Utilisez les règles d'exclusion dans l'onglet Règles :

  • Créez une règle d'exclusion basée sur le mot-clé dans le sujet
  • Ajoutez des mots comme "newsletter", "notification", "promo"
  • Ou excluez les domaines d'expéditeurs connus (ex: noreply@)

💡 Exemples de règles :

  • Exclure "newsletter" dans le sujet
  • Exclure "noreply" dans l'email
  • Exclure domaines marketing.com, newsletter.fr
Les AR sont-ils envoyés aux emails internes de mon entreprise ?

Par défaut, oui. Mais vous pouvez facilement exclure les emails internes :

  • Allez dans l'onglet 🔍 Règles
  • Créez une règle d'exclusion sur le domaine expéditeur
  • Entrez votre domaine d'entreprise (ex: monentreprise.fr)

ℹ️ Résultat : Tous les emails provenant de @monentreprise.fr seront automatiquement exclus des AR.

Puis-je modifier un template déjà en cours d'utilisation ?

Oui, vous pouvez modifier un template à tout moment, même s'il est associé à un compte actif.

  • Allez dans l'onglet 🎨 Templates
  • Cliquez sur ✏️ Modifier à côté du template
  • Effectuez vos modifications et enregistrez

⚠️ Impact : Les AR générés après la modification utiliseront immédiatement la nouvelle version du template.

Comment savoir si un AR a été envoyé à un expéditeur ?

Consultez l'onglet 📊 Analyse pour suivre en temps réel les AR envoyés :

  • Chaque événement est enregistré avec la date, l'expéditeur et la décision prise
  • Les AR créés sont affichés en vert
  • Vous pouvez filtrer par expéditeur, compte ou période

💡 Export : Exportez les données au format CSV pour une analyse externe.

Fonctionnalités avancées

Comment fonctionne la détection des doublons ?

Go2Econtact mémorise les expéditeurs auxquels un AR a été envoyé récemment :

  • Après envoi d'un AR, l'adresse de l'expéditeur est enregistrée avec un timestamp
  • Si le même expéditeur vous envoie un autre email dans la période configurée, aucun nouvel AR n'est envoyé
  • La période de détection est configurable dans l'onglet Général (1-168h, défaut 24h)

💡 Objectif : Éviter de spammer vos correspondants avec plusieurs AR pour chaque email reçu.

Puis-je forcer l'envoi d'un AR même si un doublon existe ?

Non, la détection des doublons est automatique et ne peut pas être contournée manuellement. Cependant, vous pouvez :

  • Réduire la période de détection dans l'onglet Général (ex: passer de 24h à 1h)
  • Effacer l'historique des doublons dans l'onglet Analyse

⚠️ Attention : Réduire la période de détection peut entraîner l'envoi de plusieurs AR au même expéditeur, ce qui n'est généralement pas souhaitable.

Comment exporter mes règles de filtrage ?

Actuellement, Go2Econtact ne propose pas d'export/import de règles. Cependant, vos règles sont sauvegardées localement dans Thunderbird et seront conservées :

  • Lors des mises à jour de l'extension
  • Lors des redémarrages de Thunderbird

💡 À venir : L'export/import de configuration est prévu pour une future version.

Puis-je créer des règles avec des expressions régulières (regex) ?

Non, Go2Econtact utilise un système de correspondance simple (recherche de chaîne de caractères). Les expressions régulières ne sont pas supportées dans cette version.

ℹ️ Alternative : Vous pouvez créer plusieurs règles pour couvrir différentes variantes (ex: "newsletter", "newsletters", "Newsletter").

Puis-je personnaliser le format HTML du template ?

Oui, le template supporte le HTML complet ! Vous pouvez y inclure :

  • Des styles CSS inline (<p style="color: blue;">)
  • Des images (avec balise <img>)
  • Des liens (<a href="...">)
  • Des tableaux, des listes, etc.

✓ Conseil : Utilisez le bouton 👁️ Aperçu pour visualiser le rendu HTML avant de valider.

⚠️ Limites : JavaScript n'est pas supporté dans les emails pour des raisons de sécurité.

Problèmes courants

L'extension ne se charge pas / ne s'affiche pas

Vérifiez les points suivants :

  • Version Thunderbird : L'extension nécessite Thunderbird 128.0 ou supérieur
  • Extension activée : Allez dans Modules complémentaires et vérifiez que Go2Econtact est bien activée
  • Redémarrage : Redémarrez complètement Thunderbird
  • Conflits : Désactivez temporairement les autres extensions pour tester

🔍 Diagnostic : Ouvrez la console de débogage de Thunderbird (Outils → Console d'erreurs) pour voir les éventuelles erreurs.

Erreur "Send Later introuvable"

Cette erreur signifie que l'extension Send Later n'est pas détectée. Solutions :

  • Vérifier installation : Send Later est-elle bien installée dans Modules complémentaires ?
  • Version : Send Later doit être en version 9.0 ou supérieure
  • Activation : Send Later doit être activée (pas juste installée)
  • Redémarrage : Redémarrez Thunderbird après l'installation de Send Later

🚨 Important : Go2Econtact nécessite ABSOLUMENT Send Later pour fonctionner. C'est une dépendance obligatoire.

Comment voir les logs de débogage ?

Pour consulter les logs de l'extension :

  • Ouvrez l'interface de configuration de Go2Econtact
  • Allez dans l'onglet 🐛 Logs
  • Les logs sont affichés dans un tableau avec la date, le niveau (INFO/WARNING/ERROR) et le message

Pour voir plus de détails :

  • Activez le logging détaillé dans l'onglet Général
  • Reproduisez le problème
  • Consultez les nouveaux logs

💡 Export : Vous pouvez exporter les logs au format texte pour les partager avec le support.

Les AR sont envoyés immédiatement au lieu d'être différés

Si les AR sont envoyés instantanément, c'est probablement un problème avec Send Later :

  • UUID incorrect : Vérifiez que l'UUID configuré est bien celui de votre installation Send Later
  • Send Later désactivé : Assurez-vous que Send Later est activé
  • Préférences Send Later : Vérifiez les paramètres de Send Later (peut-être un délai à 0)

ℹ️ Comportement normal : Les AR doivent apparaître dans le dossier "Drafts" de Send Later et être envoyés après le délai configuré (1-24h).

Mes statistiques sont à zéro / ne se mettent pas à jour

Les statistiques sont mises à jour au démarrage de Thunderbird. Si elles restent à zéro :

  • Redémarrer Thunderbird : Les statistiques se calculent au démarrage
  • Bouton Actualiser : Cliquez sur le bouton 🔄 Actualiser dans l'onglet Statistiques
  • Rétention : Les données de plus de 15 jours sont automatiquement supprimées

💡 Bon à savoir : Les statistiques sont locales à votre poste. Elles ne sont pas partagées entre différents PC.

Comment désinstaller proprement l'extension ?

Pour désinstaller Go2Econtact :

  • Allez dans Modules complémentaires et thèmes
  • Cherchez Go2Econtact dans la liste
  • Cliquez sur les trois points (...) → Supprimer
  • Redémarrez Thunderbird

⚠️ Données : La désinstallation supprime tous les paramètres et statistiques. Pensez à exporter votre configuration si vous souhaitez la réinstaller plus tard.

ℹ️ Send Later : Send Later peut rester installé, il fonctionne indépendamment.
