Tutoriel de configuration

Guide pas à pas pour configurer Go2Econtact en 3 étapes

⏱️ Durée estimée : 10-15 minutes

Bienvenue dans le tutoriel de configuration de Go2Econtact !

Ce guide vous accompagne étape par étape pour configurer l'extension et commencer à automatiser vos accusés de réception.

À la fin de ce tutoriel, vous serez capable de générer automatiquement des AR personnalisés pour tous vos emails externes.

📋 Prérequis

  • Thunderbird 128.0 ou version supérieure installé
  • Extension Go2Econtact installée dans Thunderbird
  • Extension Send Later (version 9.0+) installée dans Thunderbird
  • 10-15 minutes devant vous pour suivre ce tutoriel
1
Installer Send Later

Send Later est une extension Thunderbird indispensable qui permet de programmer l'envoi différé de vos messages. Go2Econtact l'utilise pour envoyer les accusés de réception après un délai configurable.

  1. Dans Thunderbird, ouvrez le menu Modules complémentaires et thèmes (raccourci : Ctrl+Shift+A)
  2. Dans la barre de recherche, tapez "Send Later"
  3. Repérez l'extension "Send Later" de Jonathan Kamens
  4. Cliquez sur le bouton Ajouter à Thunderbird
  5. Confirmez l'installation en cliquant sur Ajouter
  6. Attendez la fin de l'installation (quelques secondes)
  7. Redémarrez Thunderbird si demandé

📸 Capture d'écran à venir : Interface de recherche d'extensions dans Thunderbird

💡 Astuce : Vérifiez que la version installée est bien 9.0 ou supérieure. Les versions antérieures ne sont pas compatibles avec Go2Econtact.

⚠️ Important : Si vous désinstallez puis réinstallez Send Later ultérieurement, un nouvel UUID sera généré. Vous devrez alors mettre à jour la configuration de Go2Econtact avec ce nouveau UUID.

2
Récupérer l'UUID d'instance Send Later

L'UUID (Universally Unique Identifier) est un identifiant unique généré automatiquement par Send Later lors de son installation. Go2Econtact a besoin de cet UUID pour communiquer avec Send Later et programmer l'envoi des accusés de réception.

  1. Dans Thunderbird, cliquez sur le bouton Send Later dans la barre d'outils principale (en haut)
  2. Dans le menu déroulant qui s'ouvre, cliquez sur Send Later preferences
  3. Dans la fenêtre des préférences, allez dans l'onglet Advanced
  4. Cherchez la ligne commençant par instanceUUID dans la liste des paramètres
  5. Sélectionnez et copiez TOUTE la valeur entre les guillemets (y compris les accolades { })

📸 Capture d'écran à venir : Onglet Advanced de Send Later avec une flèche rouge pointant vers l'UUID

Exemple d'UUID :

{81339426-02d0-44e4-8af2-ca0ec9618954}

💡 Astuce : Le format de l'UUID est toujours le même : {xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx} où x représente un caractère hexadécimal (0-9, a-f).

⚠️ Attention : Ne confondez pas l'UUID d'instance (instanceUUID) avec l'ID de l'extension Send Later. Ce sont deux identifiants différents !

3
Configurer Go2Econtact

Maintenant que vous avez récupéré l'UUID de Send Later, vous allez configurer Go2Econtact pour qu'il puisse automatiser l'envoi des accusés de réception.

3.1 Configurer l'UUID Send Later

  1. Ouvrez l'interface de configuration de Go2Econtact (clic droit sur l'icône de l'extension → Options)
  2. Allez dans l'onglet 🔗 Send Later
  3. Collez l'UUID que vous avez copié à l'étape 2 dans le champ UUID Send Later
  4. Vérifiez que l'indicateur de validation passe au vert ✓
  5. Si l'indicateur reste rouge ✗, vérifiez que vous avez bien copié toute la valeur avec les accolades

3.2 Configurer vos templates d'accusé de réception

  1. Allez dans l'onglet 📝 Templates
  2. Cliquez sur ➕ Nouveau compte
  3. Saisissez l'adresse email exacte du compte pour lequel vous souhaitez activer les AR automatiques
  4. Dans la zone de texte "Template HTML", personnalisez le message d'accusé de réception

3.3 Configurer les paramètres généraux

  1. Allez dans l'onglet ⚙️ Général
  2. Renseignez votre domaine interne (ex: societe.fr) pour exclure les emails internes des AR automatiques
  3. Choisissez le délai d'envoi des AR (recommandé : 2 heures)
  4. Activez le mode test et saisissez votre adresse email personnelle pour tester sans risque
  5. Configurez vos règles d'exclusion si nécessaire (domaines, adresses, patterns à exclure)

Besoin d'aide pour configurer vos règles ?

Utilisez nos outils interactifs pour vous accompagner dans la configuration :

  • 🧙‍♂️ Assistant de configuration - Créez votre configuration en 4 étapes simples
  • 🔬 Simulateur de règles - Testez vos règles avant de les déployer

Ces outils sont particulièrement utiles pour comprendre le système d'inclusions/exclusions.

3.4 Enregistrer et tester

  1. Cliquez sur le bouton 💾 Enregistrer en bas de la page de configuration
  2. Vérifiez que tous les onglets ont une bordure verte (configuration complète)
  3. Envoyez-vous un email de test pour vérifier que tout fonctionne

Félicitations !

Votre configuration est terminée. Go2Econtact va maintenant automatiser l'envoi d'accusés de réception pour tous vos emails externes.

💡 Conseil : Gardez le mode test activé pendant quelques jours pour valider que tout fonctionne comme prévu. Une fois rassuré, désactivez-le pour passer en production.

Que faire ensuite ?

Maintenant que votre configuration de base est terminée, vous pouvez :

  • Parcourir la FAQ pour trouver des réponses aux questions courantes
  • Consulter les notes de version pour suivre l'évolution de l'extension
