Tutoriel de configuration

Mise en service en 3 étapes

⏱️ Durée estimée : 10-15 minutes

Prérequis

  • Thunderbird 115 ou version supérieure
  • Extension Go2Econtact installée dans Thunderbird
  • Extension Envoyer Plus Tard (version 9.0+) installée dans Thunderbird
1
Installer Envoyer Plus Tard

Go2Econtact s'appuie sur l'extension Envoyer Plus Tard pour expédier les accusés de réception au moment voulu. Si elle n'est pas encore installée :

  1. Dans Thunderbird, ouvrez le menu Modules complémentaires et thèmes
  2. Recherchez Envoyer Plus Tard
  3. Cliquez sur + Ajouter à Thunderbird
  4. Redémarrez Thunderbird si demandé
À retenir : si vous désinstallez puis réinstallez Envoyer Plus Tard, un nouveau code d'identification sera généré. Vous devrez alors revenir à l'étape 2 pour le mettre à jour dans Go2Econtact.
2
Récupérer le code d'identification Envoyer Plus Tard

Pour que Go2Econtact et Envoyer Plus Tard puissent communiquer, Go2Econtact a besoin d'un code d'identification propre à votre installation d'Envoyer Plus Tard. Ce code est généré automatiquement lors de l'installation — il est donc unique à votre poste de travail.

  1. Dans Thunderbird, ouvrez le menu Modules complémentaires et thèmes
  2. Repérez l'extension Envoyer Plus Tard et cliquez sur son icône pour accéder à ses options
  3. Vérifiez que l'onglet Options est bien sélectionné, puis faites défiler la liste jusqu'à la section Avancé
  4. Cliquez sur Éditeur de configuration avancé pour déplier la liste des paramètres, puis faites défiler jusqu'à la ligne instanceUUID
  5. Sélectionnez l'identifiant complet accolades comprises à la souris, puis copiez-le (Ctrl+C)

Exemple de code :

{2d4226fb-0ea1-44ea-a32b-2e2181d39134}
Attention : ne confondez pas ce code d'identification avec l'identifiant de l'extension Envoyer Plus Tard elle-même — ce sont deux choses différentes.
3
Configurer Go2Econtact

Ouvrez la configuration de Go2Econtact : clic droit sur l'icône de l'extension dans Thunderbird → Options.

3.1 Saisir le code d'identification Envoyer Plus Tard

  1. Allez dans l'onglet Envoyer Plus Tard de Go2Econtact, collez le code dans le champ prévu
  2. Un indicateur passe au vert ✓ si le code est reconnu comme valide — il est enregistré automatiquement
  3. S'il reste rouge ✗, vérifiez que vous avez bien copié l'intégralité du code, accolades incluses

3.2 Configurer votre modèle de message

  1. Allez dans l'onglet Modèles
  2. Sélectionnez l'adresse à configurer dans la liste déroulante — un indicateur visuel précise si un modèle est déjà configuré pour ce compte
  3. Rédigez votre message d'accusé de réception dans la zone de texte, ou cliquez sur Charger défaut pour démarrer avec un modèle prêt à l'emploi
  4. Cliquez sur Aperçu pour visualiser le rendu
  5. Cliquez sur Sauvegarder

3.3 Paramétrer l'onglet Configuration

L'onglet Configuration regroupe les règles de filtrage, le délai d'envoi (1 heure par défaut), le mode test et les autres réglages. Consultez la documentation pour le détail de chaque paramètre.

Pour préparer vos règles de filtrage, vous pouvez utiliser l'Assistant ou le Simulateur disponibles sur ce site.

3.4 Enregistrer et tester

  1. Cliquez sur Enregistrer la configuration en bas de l'onglet Configuration
  2. Vérifiez que les onglets Envoyer Plus Tard, Modèles et Configuration ont une bordure verte
  3. Activez le mode test dans l'onglet Configuration et saisissez votre adresse personnelle
  4. Envoyez-vous un courriel de test et vérifiez que vous recevez bien l'accusé de réception
Conseil : laissez le mode test activé quelques jours pour vous assurer que tout fonctionne comme prévu. Une fois rassuré, décochez-le pour passer en utilisation réelle.
