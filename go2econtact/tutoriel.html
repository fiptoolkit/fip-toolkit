Tutoriel de configuration

Mise en service en 3 étapes

⏱️ Durée estimée : 10-15 minutes

Prérequis

  • Thunderbird 115 ou version supérieure
  • Extension Go2Econtact installée dans Thunderbird
  • Extension Send Later (version 9.0+) installée dans Thunderbird
1
Installer Send Later

Go2Econtact s'appuie sur l'extension Send Later pour expédier les accusés de réception au moment voulu. Si elle n'est pas encore installée :

  1. Dans Thunderbird, ouvrez Modules complémentaires et thèmes (Ctrl+Maj+A)
  2. Recherchez Send Later
  3. Installez l'extension de Jonathan Kamens
  4. Redémarrez Thunderbird si demandé
📸 Capture d'écran — résultat de recherche "Send Later" dans les modules Thunderbird
À retenir : si vous désinstallez puis réinstallez Send Later, un nouveau code d'identification sera généré. Vous devrez alors revenir à l'étape 2 pour le mettre à jour dans Go2Econtact.
2
Récupérer le code d'identification Envoyer Plus Tard

Pour que Go2Econtact et Envoyer Plus Tard puissent communiquer, Go2Econtact a besoin d'un code d'identification propre à votre installation d'Envoyer Plus Tard. Ce code est généré automatiquement — il est unique à votre poste.

  1. Dans Thunderbird, ouvrez le menu Modules complémentaires et thèmes
  2. Repérez l'extension Envoyer Plus Tard et cliquez sur son icône pour accéder à ses options
  3. Vérifiez que l'onglet Options est bien sélectionné, puis faites défiler jusqu'à la section Avancé
  4. Cliquez sur Éditeur de configuration avancé pour déplier la liste, puis faites défiler jusqu'à la ligne instanceUUID
  5. Sélectionnez l'identifiant complet accolades comprises à la souris, puis copiez-le (Ctrl+C)
📸 Capture d'écran — onglet Advanced de Send Later, ligne instanceUUID surlignée

Exemple de code :

{81339426-02d0-44e4-8af2-ca0ec9618954}
Attention : ne confondez pas ce code d'identification avec l'identifiant de l'extension Send Later elle-même — ce sont deux choses différentes.
3
Configurer Go2Econtact

Ouvrez la configuration de Go2Econtact : clic droit sur l'icône de l'extension dans Thunderbird → Options.

3.1 Saisir le code d'identification Envoyer Plus Tard

  1. Allez dans l'onglet Envoyer Plus Tard
  2. Collez le code copié à l'étape 2 dans le champ prévu
  3. L'indicateur doit passer au vert ✓ — s'il reste rouge ✗, vérifiez que les accolades sont bien incluses
📸 Capture d'écran — onglet Send Later avec indicateur vert

3.2 Configurer votre modèle de message

  1. Allez dans l'onglet Modèles
  2. Sélectionnez l'adresse à configurer dans la liste déroulante
  3. Rédigez votre message d'accusé de réception dans la zone de texte, ou cliquez sur Charger défaut pour démarrer avec un modèle prêt à l'emploi
  4. Cliquez sur Aperçu pour visualiser le rendu
  5. Cliquez sur Sauvegarder
📸 Capture d'écran — onglet Modèles avec éditeur et aperçu

3.3 Paramétrer l'onglet Général

L'onglet Général regroupe les règles de filtrage, le délai d'envoi, le mode test et les autres réglages. Consultez la documentation pour le détail de chaque paramètre.

Pour préparer vos règles de filtrage, vous pouvez utiliser l'Assistant ou le Simulateur disponibles sur ce site.

3.4 Enregistrer et tester

  1. Cliquez sur Enregistrer la configuration en bas de l'onglet Général
  2. Vérifiez que les onglets Send Later et Modèles ont une bordure verte
  3. Activez le mode test dans l'onglet Général et saisissez votre adresse personnelle
  4. Envoyez-vous un courriel de test et vérifiez que vous recevez bien l'accusé de réception
📸 Capture d'écran — fenêtre de configuration avec onglets à bordure verte
Conseil : laissez le mode test activé quelques jours pour vous assurer que tout fonctionne comme prévu. Une fois rassuré, décochez-le pour passer en utilisation réelle.
